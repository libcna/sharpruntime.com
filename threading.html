Threading

Thread, synchronization primitives, CancellationToken, Timer, and Tasks.

ℹ Implementation note
Threading primitives are backed by C++ <thread>, <mutex>, <atomic>, and <condition_variable>. Task and channel APIs are available as separate components; C# language-level async/await syntax has no direct C++ equivalent. Thread safety is not universally guaranteed — check per-class documentation.

    // thread body

});
t.Start();

CancellationToken

modules/threading/include/System/Threading/CancellationToken.hpp | modules/threading/src/System/Threading/CancellationToken.cpp

Status: Done

System::Threading::CancellationTokenSource cts;
auto token = cts.getTokenProperty();

// In a thread:
while (!token.getIsCancellationRequestedProperty()) {
    // do work
}

// Cancel from another thread:
cts.Cancel();

Status: Done

    std::cout << "tick\n";
}, nullptr,
/*dueTime=*/1000,    // ms before first fire
/*period=*/500);     // ms between fires

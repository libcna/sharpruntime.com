Threading, Tasks and Timers

Native threads, synchronization, cancellation, tasks, channels and timer behavior.

ConceptsSource f827a6c5

Threading

Thread, mutex, semaphore, monitor and cancellation-shaped surfaces use native synchronization. Thread safety is per type; a namespace name does not make global state safe.

Tasks

Task and continuation APIs support porting patterns, but C++ syntax and native scheduling remain explicit. There is no synchronization context supplied by a CLR.

Channels and timers

Channels provide producer/consumer flow; timers schedule callbacks. Both require explicit cancellation, completion and lifetime protocols.

Shutdown is a design

Destroying an owner while work, continuations or timer callbacks can still touch it is unsafe. Build teardown into the API.

Known Limitations

Current non-goals, partial APIs, platform limits and known verification gaps at the pinned Sharp Runtime revision.

DevelopmentSource f827a6c5

Deliberate non-goals

  • CLR/JIT/GC and arbitrary managed assembly execution
  • General reflection/member enumeration and DynamicInvoke
  • P/Invoke, remoting and AppDomain assembly infrastructure
  • BinaryFormatter-style general serialization
  • C# language async/await in C++

Security boundary

Implemented hashing, HMAC, PBKDF2 and secure random are not a complete cryptographic platform. Encryption algorithms, certificates, TLS, HTTPS, WSS and SslStream are not part of the current public promise.

Platform/compiler limits

  • Current hosted CI validates Ubuntu only.
  • MSVC lacks the native __int128 capability used by some numeric surfaces.
  • Emscripten cannot provide several native DNS/network/process/filesystem facilities.
  • Android storage expects SDL3 from the parent build.
  • Console cursor/color behavior is ANSI-terminal oriented.

High-impact current limitations

  • Network transport: HTTP is buffered plain HTTP/1.1 over TCP; no redirects or TLS. WebSockets support ws://, not wss://.
  • Async lifetime: several socket, HTTP and WebSocket task wrappers capture raw owners or caller buffers; keep them alive until completion.
  • Text/globalization: Unicode normalization is effectively ASCII/no-op beyond the reduced surface; several encoding indices count UTF-8 bytes; culture, collation, casing and grapheme behavior are limited.
  • Time zones: Windows/POSIX paths exist, but the model largely uses fixed current offsets with no transition rules, ambiguity/invalid-time model or serialized form.
  • Storage: isolated storage is organizational, not a security sandbox. Use trusted relative paths; absolute paths, .. and symlink confinement are not comprehensively contained.
  • Platform APIs: FileSystemWatcher and NetworkInterface are Linux-specific; Process is POSIX-only; Emscripten threading requires pthreads and whole-program/browser configuration.
  • Compiler boundary: Decimal/Int128/UInt128 surfaces require native __int128, limiting current MSVC/i686 coverage.

Known full-gate conditions

The latest controlled recorded full gate had six failed: five Ping cases were triggered by ping_group_range and expose a real missing raw-ICMP receive fallback; one socket/interface case depended on a missing /proc/net/if_inet6. The current pinned source adds 31 passing TimeZone cases after that record; no post-merge controlled full-gate result is claimed.

A limitation page, not an audit-ticket dump

Internal audit findings are translated into user-facing behavior here. Fixed findings and project-management identifiers are not published as if they were current defects.

Type System and Core Values

Primitive aliases, wrappers, Object, Type, nullable, enums, date/time and conversions.

Type categories

CategoryExamplesNative consideration
Primitive aliasesintcs, longcs, byte/unsigned aliasesFixed intent, but C++ overload/formatting rules apply
WrappersNumeric and value wrappersCopyable native values with curated .NET-shaped APIs
Object / TypeBase identity and runtime type namingNot a CLR metadata graph
Array / Span / MemoryOwned sequences and borrowed viewsView lifetime must not exceed backing storage
Nullable / enumsOptional/value and enum compatibility helpersTemplate and C++ enum semantics remain visible
Date/timeDateTime, DateOnly, TimeOnly, TimeSpan, TimeZoneInfoLocal-zone and platform data matter

Conversion and validation

Conversions and parsers are implemented per type. Edge behavior—including overflow, separators, culture and Try-output rules—has been an active compatibility-audit area; consult tests when contributing rather than copying an old overview count.
